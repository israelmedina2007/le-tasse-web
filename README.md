# Le Tasse · La Paz

Propuesta web independiente para Le Tasse, Baja California Sur.

`index.html` contiene la página completa con imágenes, estilos y JavaScript integrados. Descárgalo y ábrelo en Safari, Chrome o Firefox. También puede publicarse directamente en un alojamiento estático.

`codigo-fuente.zip` contiene el código organizado y sus recursos para editarlo. No requiere compilación.

Las fuentes y notas están indicadas en la web y el archivo LEEME del paquete. Horarios y precios pueden cambiar. Propuesta de diseño sin afiliación oficial; las marcas y fotografías pertenecen a sus titulares.
